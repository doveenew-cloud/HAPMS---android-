# HAPMS — njia ya kujenga APK kupitia GitHub

Hiki ni kifurushi cha chanzo cha demo ya Android pamoja na GitHub Actions workflow ya kujenga APK kwenye cloud. **Si APK yenyewe.**

## Jinsi ya kupata APK kwa kutumia simu
1. Fungua https://github.com na uingie/ufungue akaunti.
2. Bonyeza `+` kisha `New repository`. Ipe jina `HAPMS`, chagua `Public` au `Private`, kisha `Create repository`.
3. Kwenye ukurasa wa repository, chagua `Add file` > `Upload files`.
4. Fungua ZIP hii kwenye simu, kisha pakia yaliyomo yote ya folda ya mradi (hakikisha folda ya `.github` nayo imepakishwa). Commit changes.
5. Fungua tab ya `Actions`, chagua `Build HAPMS APK`, bonyeza `Run workflow`.
6. Ikimaliza kwa alama ya kijani, fungua run hiyo, nenda `Artifacts`, pakua `HAPMS-Android-APK.zip`, ifungue na utapata `app-release.apk`.

## Muhimu
- APK itakayojengwa ni DEMO ya mwonekano wa mwanzo tu.
- Haijahifadhi bidhaa, mauzo au matumizi; haina login halisi na haijaunganishwa na backend/database.
- Ujenzi wa APK lazima ukamilike kwa mafanikio kabla ya kuipakua.
- Usishiriki password yako ya GitHub na mtu yeyote.
